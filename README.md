# Fabledom Multiplayer (Co-op Mod)

Кооперативный режим для игры **Fabledom**, позволяющий двум и более игрокам строить королевство вместе в реальном времени.

## Возможности
- **Синхронизация курсоров и положения камеры**: отображение 3D-маркеров курсоров, никнеймов и рамок зоны обзора других игроков на карте.
- **Синхронизация строительства**: передача команд возведения зданий между хостом и клиентом в реальном времени.
- **Интеграция в главное меню**: аккуратная кнопка «Кооператив» в стилистике оригинальной игры.
- **Минималистичный интерфейс лобби**: выбор роли (Хост / Клиент), выбор режима игры (Новая игра / Загрузка сохранения) или ввод IP-адреса для подключения (поддержка локальной сети и Porthole / Radmin / ZeroTier).
- **Сетевой движок**: встроенный асинхронный TCP-сервер и клиент без необходимости внешних платных сервисов.

## Установка
1. Установите [BepInEx 5.4+ (x64)](https://github.com/BepInEx/BepInEx/releases) в директорию игры:
   `...\Steam\steamapps\common\Fabledom\`
2. Соберите проект или скачайте скомпилированный `FabledomMultiplayer.dll`.
3. Поместите `FabledomMultiplayer.dll` в папку `BepInEx/plugins/`.
4. Запустите игру.

## Сборка
```bash
dotnet build -c Release
```
*(Пути к сборкам Fabledom и BepInEx настроены в `FabledomMultiplayer.csproj`)*
